🚀 QUICK START
────────────────────────────────────────────────────────────────────────────

1. Open in Godot 4.3+
   $ cd /workspaces/Only-player
   $ godot --path .

2. Create Main.tscn scene (follow SCENE_STRUCTURE.md)
   • Manually create scene hierarchy
   • Attach scripts to nodes
   • Configure collision shapes

3. Test controls
   • F5 to play
   • WASD + Mouse (keyboard)
   • Joysticks (touch simulation)

4. Export to mobile
   • Android: Project > Export > Android
   • iOS: Project > Export > iOS
